# Anime365 for Seanime

Streaming provider for Seanime.

1. Host `manifest.json` and `provider.ts` over HTTPS. Replace `YOUR_HOST` in both manifest URLs.
2. Install the manifest URL in Seanime under **Extensions → Add extension**.
3. Enter your personal Anime365 API token in the extension settings and select Anime365 for online streaming.

An active Anime365 subscription is required. Keep your token out of public files; Seanime user settings are not guaranteed to be secret storage.
